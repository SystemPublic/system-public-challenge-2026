Find

From 5.9 million findings to 38 pathways

Join two well-studied halves: medicine → body effect ← heat.

For 22 of these 38, no study has tested the medicine in the heat; System connects the two halves.

Check

Did System read the papers the same way we did?

We pulled every number from each paper ourselves. System pulls numbers from papers too. Where both read the same paper, we compared.

System nearly always found the same result as us. If the results were different, we hid the data from our service.
