## Evidence scoring (spec §9)

literature_score = design_weight x study_factor x consistency x population_match, where design_weight and population_match come from the public literature HARM claim with the highest design_weight x population_match (all claims if none shows harm, so a strong null study never inflates the harm meter); study_factor = min(1, log2(1+n)/log2(1+5)) with n = distinct public literature sources; consistency = share of directional public literature claims in the majority direction (harm vs null), 0.5 if none. Meter: Strong >= 0.45, Some >= 0.2, else Early signs. Only layer=literature claims with badge != '?' count. System graph pathways and FAERS are reported in their own fields and are never multiplied in.

Design weights (8-step tier):

- 1 RCT / meta-analysis: 1.0
- 2 Population study: 0.8
- 3 Small clinical / PK study: 0.6
- 4 Case series: 0.45
- 5 Case report: 0.3
- 6 Lab / bench / field test: 0.25
- 7 Label or guidance only: 0.15
- 8 Mechanism only / no study found: 0.05

Population match:

- `patients_in_heat`: 1.0
- `subgroup_in_heat`: 0.85
- `lab_heat_healthy`: 0.6
- `indirect`: 0.5
- `mechanism`: 0.3

Study factor saturates at 5 independent sources. Meter thresholds: Strong >= 0.45, Some >= 0.2.

### FLAG vs CHANGE

FLAG ('Check on this person') = association strength, causal or not: max over public literature harm claims of design_weight x population_match x severity (1.0 High, 0.75 Moderate) + 0.15 if FAERS specific-composite signal clears the negative-control band + 0.10 if any FDA label carries a heat warning + 0.10 if >= 6 of 8 jurisdictions mention it. High >= 0.6, Moderate >= 0.3. CHANGE ('Rethink the medicine') = literature_score x causal_factor + 0.10 if a cited lower-heat-risk alternative exists. causal_factor = 1.0 when the drug's own mechanism is shown in humans, 0.5 when within-person or adjusted studies show no added drug effect (confounding by indication), 0.75 otherwise; for storage/absorption drugs CHANGE concerns handling, not the molecule. High >= 0.45, Moderate >= 0.2; CHANGE is capped at Moderate when causal_factor <= 0.5. Strong within-person studies showing no added drug effect -> high FLAG, lower CHANGE (spec §9).

### Badges

- ✓✓ number found verbatim in the abstract AND System (Dataverse v2.1 `system_master_list_study_findings.csv`, or System API verification when present) has the same value.
- ✓ citation exists (PubMed/Crossref check in `citation_verification.csv` or abstract in `abstracts.jsonl`) and every claimed number is verbatim in the abstract; or a guidance quote verbatim in the coded source; or a computed FAERS/label value from cached openFDA data.
- ↗ System graph two-hop pathway (drug -> mediator <- heat) with >= 3 drug-leg studies, non-BP mediators only. Graph layer; never in the literature score.
- ⚠ System value or API check conflicts with ours.
- ? no citation id, citation not found, or number not in abstract. **Never public**: excluded from label lines, patient messages, the meter and FLAG/CHANGE.
