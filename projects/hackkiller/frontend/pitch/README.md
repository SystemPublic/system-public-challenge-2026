# Malaria Atlas · HackKiller pitch

The public presentation opens at the `/pitch/` path of this repository's published static frontend. Open `index.html` through an HTTP server, or use `Open Presentation.command` for a local rehearsal.

The deck includes three formal slides, a working copy of the supplied product, embedded backup screens, navigation controls and a timer. The product reads the bundled schema 1.0.1 snapshot and needs no API key. Source-paper links open online. The Budget & Coverage Planner uses the assumptions entered by the viewer.

`speaker-script.md` contains the three-minute English script, click sequence, fallback wording and source explanations. `product/` contains the supplied frontend with local fonts, snapshot loading and fixes found during deployment testing. `assets/` holds the actual product captures, plotted paper estimates and fonts. The source download includes these files.

The presentation reflects the supplied project archive dated 14 November 2026. HackKiller members are ZiyaoDai, Chloe Wang, Kevin Qian, Yuqing Ji and Xinyi Zhao. The repository's top-level `frontend/` continues to carry the team's main application.

D3 and fonts retain the license notices shipped with them. Full data provenance is documented in the repository's main README and in the bundled record fields.
