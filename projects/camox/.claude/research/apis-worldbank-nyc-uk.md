## Manual steps needed (a human must register; none done here)

1. **EPC register (E1):** go to `https://get-energy-performance-data.communities.gov.uk/guidance/energy-certificate-data-apis` → "Sign in or create an account" (GOV.UK One Login: email, password, phone code) → copy the bearer token from the "My account" page → store as `EPC_BEARER_TOKEN` in `.env`. Only needed for per-property EPC data; aggregates can wait.
2. **NYC Open Data app token (B4, optional but recommended):** sign in at `https://data.cityofnewyork.us` (Tyler Data & Insights ID) → profile → Developer Settings → "Create New App Token" → store as `SOCRATA_APP_TOKEN`, send as `X-App-Token`. Required only for SODA3 or heavy use; SODA 2.1 works without it.
3. **NOAA CDO token (optional):** request at `https://www.ncdc.noaa.gov/cdo-web/token` (email only; token arrives by email). Not needed if using NCEI Access Data Service.
4. **Underlay write key (only if the team publishes its own collection for B4):** sign in at `https://www.underlay.org/login` (KF Auth SSO) → Settings → API Keys; org membership via help@underlay.org. Reads need nothing.
5. **Not hackathon-feasible:** GLD / Enterprise Survey microdata (Microdata Library account + per-study approval) and EHS microdata (UK Data Service account + End User Licence). Use Data360 / ILOSTAT aggregates and EHS published tables instead.
