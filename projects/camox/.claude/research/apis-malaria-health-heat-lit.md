UNVERIFIED = taken from docs or search results only, not tested.

## Manual steps needed (a person has to do these)

1. **OpenAlex API key (recommended before the team starts):** a team member signs in at `https://openalex.org/settings/api` and creates a free key ($1/day), then adds `api_key=...` to requests. Without it, everyone on the same IP shares $0.10/day.
2. **CDC Tracking Network API token (V3, only if county heat-health data is needed):** email trackingsupport@cdc.gov to request a token. Unauthenticated calls returned 429 straight away. Turnaround is unknown; may not arrive during the hackathon.
3. **NOAA CDO token (optional):** request it by email at `https://www.ncdc.noaa.gov/cdo-web/token`. Not needed if you use the NCEI Access Data Service v1, which worked without a token.
4. **MalariaGEN Google Cloud access (optional, full Pf8 genotype calls only):** use a Google account, submit the MalariaGEN cloud data access form (linked from `https://malariagen.github.io/parasite-data/cloud_data_access/parasite-cloud-data-access.html`), wait for approval, then run `gcloud auth application-default login`. Not needed for marker-level work: the Zenodo TSVs are open.
5. **WWARN/IDDO individual patient data (not feasible at the hackathon):** Data Access Application plus Data Use Agreement, approved by the IDDO DAC or the data contributor. The surveyor CSV export is manual (whether it needs a login is UNVERIFIED).
6. **DHS API key (optional):** register with DHS as an API partner for larger pages. Not needed at hackathon scale. The DHS MCP endpoint needs auth (401).
