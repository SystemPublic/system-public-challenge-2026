What changes when new evidence arrives

The System graph links variables by findings from papers. We treat each link as a running meta-analysis, add New York’s registered test to it, and draw each change as a strip of frames.

98 predictions registered before the data were read. 97 scored. Referees changed eleven verdicts. Today: four new tests, a replication in a second city, and strips drawn by a script from the Underlay.

Ida Benedetto and Jeff Nickerson · Team Hypergraph · nyc-concordance

Say the idea first. A graph of findings is never finished: a study, a dataset or a placebo arrives and an old link has to be read again. We built the procedure for that (register, test, referee) and a drawing for it (the strip). This slide follows the moon. Say the idea, then take the same procedure to heat and shootings.
