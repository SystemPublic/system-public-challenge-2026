System Build Challenge 4 · 14 November 2026

What changes when new evidence arrives

The System graph links variables by findings from papers. We treat each link as a running meta-analysis, add New York’s registered test to it, and draw each change as a strip of frames.

97 predictions registered before the data were read. 96 scored. Referees changed eleven verdicts. This morning one test narrowed five conjectures and set aside one of our own.

Ida Benedetto and Jeff Nickerson · Team Hypergraph · nyc-concordance

Say the idea first. A graph of findings is never finished: a study, a dataset or a placebo arrives and an old link has to be read again. We built the procedure for that (register, test, referee) and a drawing for it (the strip). The worked example is heat and shootings.
