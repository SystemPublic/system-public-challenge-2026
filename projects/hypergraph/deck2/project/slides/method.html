Method

Each prediction is written down and timestamped before its data are read

1

Read the graph for the shape and size of an effect

2

Chain findings to predict the city effect

3

Drop tests that could not fail

4

Register: hash, commit, push a branch

5

Test on city data with recorded versions

6

A blind referee reruns the deciding number

Disagreements go back to the graph as candidate errors. Twelve reading rules came out of referee criticism, for example: a measure chosen after seeing the data never decides a verdict.

Each registration states direction, size, the condition for support, the condition for refutation, alternative explanations and a prior. It is hashed and pushed to its own branch on GitHub before any city data are queried, which gives an outside timestamp. Referees receive the code and data but not the registrant's reasoning.
