Twelve of the 93 scored claims are packaged; the steps shown are for heat-shootings. python tools/replicate.py CLAIM_ID writes replication/CLAIM_ID/ with manifest.json, inputs/ (copies up to 15 MB, or 20 MB for the first two; larger files by hash), code/, requirements.txt, run.sh and verify.py. The --underlay option writes the inputs and manifest as records ready to push, so each number in the talk can resolve to a fixed Underlay version with an ARK.
