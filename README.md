# System Public Challenge 2026

Projects built on the [System Public Graph](https://www.system.com/public) at the System Public Challenge, New York, November 14, 2026.

## How to submit

Submit by opening one pull request per team **before 3pm ET on November 14**.

1. **Fork this repo.** Click **Fork** at the top right of this page.
2. **Copy the template.** In your fork, create a folder `projects/<team-name>/` using lowercase letters and hyphens (for example, `projects/good-job-mappers/`). Copy `TEMPLATE/README.md` into it and fill it in.
3. **Build your project** inside that folder.
4. **Open a pull request.** In your fork, click **Contribute → Open pull request**. Title it `Team name: Challenge` (for example, `Good Job Mappers: Explore 2`).
5. **Add the link to Devpost.** Paste your pull request link into the "Try it out" field of your Devpost submission.

You can keep pushing changes to your pull request until 3pm.

## Requirements

- Put everything in your team's folder, `projects/<team-name>/`. Don't change files outside it.
- Fill in your folder's README from the template, including how to run your project, your data sources and whether you used AI coding tools.
- **Never commit API keys or passwords.** Put your key in a `.env` file, which this repo ignores. See the template for how.
- Keep each file under 25 MB. If you need a large dataset, include a script that downloads it instead.

## Submitting without Git

You can do everything in your browser:

1. Click **Fork** on this page.
2. In your fork, click **Add file → Upload files**. In the box at the top, type `projects/<team-name>/` and drag in your files.
3. Click **Commit changes**.
4. Click **Contribute → Open pull request**.

Need help? Post in **#help** on the hackathon Slack.
